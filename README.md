# ValoMaths (archived)

ValoMaths is a Valorant match-analytics site. It scores every player's rounds with a custom "Impact" score based
on kill order, economy state, post-plant timing and trade windows.

**This repository is archived and no longer deployed.** Development continues in
[conorlum/valo-with-friends-tracker](https://github.com/conorlum/valo-with-friends-tracker), which now builds the site.

- **Live demo:** https://valomaths.onrender.com. It runs on a small set of sample matches.
- **Source:** [conorlum/valo-with-friends-tracker](https://github.com/conorlum/valo-with-friends-tracker). The demo
  is that codebase running in demo mode (`DEMO_MODE=true`, `SITE_NAME=ValoMaths`).

The code here is kept for history only, and its `render.yaml` is no longer connected to any Render service.
